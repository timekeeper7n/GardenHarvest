# MUV-LUV 少女庭园 自动挖矿脚本

一个类似 MAA 的个人用脚本：截图识别游戏画面 + 自动点击，自动刷挖矿（肉鸽爬塔）模式，
自动结算并把强化商店里的矿花掉。

## 启动方式

- **双击 `MuvLuvMiner.exe`**（单文件版：模板和默认配置已内嵌，放到任何
  空文件夹都能独立运行；首次运行自动在旁边生成可编辑的 config.json；
  窗口界面：开始/停止 + F12 热键 + 目标轮数 + 适配模式 + 实时日志）
- 或双击 `start_miner.bat`（源码命令行版，需 Python 环境）

任何分辨率/缩放比例/窗口大小自动适配（坐标实时校准），换电脑直接拷
exe 即可。

## 原理

脚本每隔约 1 秒给游戏窗口截图（窗口被遮挡没关系，不能最小化），
自动裁掉浏览器界面、缩放成 1280x720 标准画面（因此**窗口大小、屏幕分辨率、
缩放比例都随意**），再和 `templates` 文件夹里的按钮图片逐一比对。
认出画面后按 `config.json` 里配置的动作点击。整个流程是"画面 -> 动作"的
对照表，改流程不用改代码。

## 文件结构

```
muvluv_miner/
├─ MuvLuvMiner.exe     ★ 图形界面版（双击运行）
├─ start_miner.bat     命令行版启动
├─ miner_gui.py        界面源码
├─ miner.py            主脚本源码（状态机循环）
├─ core.py             核心库：找窗口/截图/标准化/识别/点击
├─ config.json         ★ 配置：每个画面点什么、商店流程的具体步骤
├─ check_window.py     诊断：确认窗口能找到、截图裁剪是否正确
├─ start_capture.bat   截图工具（F2 截图，F10 退出，做模板用）
├─ make_buff_template.bat 一键重做 buff SELECT 模板
├─ tools/              辅助工具（抠图/验证）
├─ templates/          按钮模板图片
└─ screenshots/        截图存档（unknown 子文件夹 = 没认出来的画面）
```

## 挖矿流程（当前配置）

```
模式主界面 → 出击
→ 配队 → 出击
→ 路径选择 → 右下红色继续（不识别路径）
→ [战斗自动进行]
→ 单场胜利结算 → 继续
→ buff选择 → 点最右 SELECT
→ 局内商店/支援选择 → 右下白色继续（不买东西）
→ 模式总结算 → 右下继续（计数一轮）
→ 强化商店：倍率点2下(MAX) → 3个项目(タイブ装備/採掘/アーティファクト,
  跳过每日商店) × 3个子项 × 5个商品位全部点一遍 → 点白色[完了]退出
   → (矿残留弹窗 → 红色确定)
→ 回到模式主界面，循环
```

商店坐标换算说明：给脚本配置的坐标是 1280x720 标准坐标。如果在
150% 缩放的屏幕上量物理坐标（最大化窗口），换算公式：
标准x = 物理x / 2，标准y = (物理y - 126) / 2

## 使用

**运行前提**（重要）：
- 游戏窗口**最大化或全屏**，并且**不被其他窗口遮挡**（截图直接取屏幕
  真实像素，被挡住的部分会截到挡住的窗口；点击本来也要求窗口可见）
- 运行期间鼠标会被脚本接管，别同时用电脑

步骤：
1. 打开游戏，进入挖矿模式主界面附近
2. 双击 `start_miner.bat`，**F12 随时停止**
3. 没认出来的画面会自动存到 `screenshots/unknown/`，把截图发我就能补模板

## 挂机建议

- **自动停止**：config.json 顶部 `target_runs` 改成数字（比如 10），
  跑完 10 轮自动停；0 = 无限循环
- **连续 20 次识别失败会自动停**（`max_unknown` 可调），防止异常时乱点。
  作战和加载画面属于"未识别"，是正常现象不算故障
- **未知画面截图默认关闭**（避免成品越用越大）：需要排查新画面时，
  把 config.json 的 `save_unknown` 改为 true，复现后截图会存到
  `screenshots/unknown/`
- 挂机时别用这台电脑的鼠标（点击会互相打架）
- 遇到活动更新、界面改版后识别失败：开 save_unknown 复现，把截图
  发给 AI 补模板即可

## 常见问题

- **找不到窗口**：改 `config.json` 的 `window_keyword`（运行 check_window.py
  会列出所有窗口标题）。
- **识别不到**：看 `screenshots/unknown/` 的存图，做成新模板加进 config.json；
  或把 `threshold` 从 0.8 降到 0.7。
- **误识别/点错**：`threshold` 升到 0.85~0.9。
- **点太快没反应**：把该屏的 `wait` 加大 1~2 秒。
- **点击期间鼠标被抢走**：正常现象，脚本用真实鼠标点击，挂机时别用电脑。
