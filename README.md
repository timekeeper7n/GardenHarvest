# GardenHarvest
一款完全由GLM模型生成的MUV-LUV少女庭园挖矿自动脚本

因为是纯AI编程，所以比较简陋，限制可能也会比较大。目前已知在2560×1600比例150%缩放的窗口全屏和小窗运行稳定，但其它分辨率窗口暂无样本测试（不过也有要求AI做相应的缩放换算）。

使用方法只能搭配翻译项目“MuvluvMod”的自动跳过战斗使用，因为没有写跳过命令。

开始时请打开挖矿模式界面并选择好对应的层数，因为本脚本只是简单的点击指令，没有记录不同buff和遗物的决策，所以默认选择右边的buff和默认路线。同时不会进入商店和选择支援角色。

最后结算商店设定每日商品部分不做购买，其他加点有上到下由左到右购买。

最后，因为本人刚玩这款游戏两天所以很多东西可能会有遗漏，本脚本只适用于还没有把加成点满的“萌新（？）”功能十分有限在此致歉。
